# MCA CET Prep

Free preparation for **MAH-MCA-CET**, the Maharashtra MCA Common Entrance Test, where **every topic is explained with an everyday analogy**.

**Live site: https://baluraut.github.io/mca-cet-prep/** · **मराठी: https://baluraut.github.io/mca-cet-prep/mr/**

The whole site is also available **in Marathi (मराठी)**. Every analogy, concept, formula sheet, worked example, trap and answer explanation is written in Marathi, and technical terms are given as मराठी (English). Practice and mock-test questions stay in English, because the real exam is English-only, and a Marathi meaning is shown with each question. Use the **मराठी / English** button on any page to switch languages without losing your place.

Each topic page follows the same path:

1. **Think of it like…** An analogy from daily life (a cricket ball, a local train, a kirana shop, a dabbawala), with a table mapping each everyday idea to the exam idea.
2. **The concept**, explained in plain English.
3. **Key points & formulas**, which double as the formula sheet.
4. **A worked example**, with the solution hidden until you want it.
5. **Exam shortcut** and **common traps**.
6. **Practice MCQs**. Tap an option to see whether it's right, with an explanation.

You can also use:

- a **20-question diagnostic** to take first: it scores each section and tells you which one to study first;
- a **word list**: 200 high-frequency exam words with meanings, synonyms, antonyms, Marathi meanings and example sentences, in twenty days of ten, with flashcards and an auto-generated synonym/antonym quiz;
- **retry my mistakes**: every question you answer wrongly, on a topic page or in a test, collects in one place until you get it right;
- a **mock test** with a full 100-question paper in the real 30/30/20/20 split and a 90-minute timer, or a 10-question drill per section, followed by a section-wise score, time spent per question (the exam allows 54 seconds each), a list of weak topics and answer review;
- a printable **revision sheet** that gives the one-line analogy and key formulas for every topic;
- a **previous papers** guide: where past MCA CET papers can actually be found (the official one is only in the candidate login), what each source really contains, the question types past papers show mapped to topics here, and how to practise with one;
- an **8-week study plan** that mixes all four sections each week, and a **day-by-day version** (56 days: one or two topics, ten words, drills, retries and mocks) that highlights today's row once you press "Start the plan today";
- a **speed-maths table** on the revision sheet (squares, cubes, powers of 2, fraction↔percent, divisibility rules, constants, trig values), generated by the build so the values are exact;
- an **exam-day checklist** taken from the official brochure;
- **progress tracking**: tick a topic as done and it is remembered in your browser; the home page shows your diagnostic result, last score and mistakes to retry;
- **offline use**: after the first visit the whole site is cached by a service worker, so it opens without a data connection.

## Exam pattern

These figures come from the official [MAH-MCA-CET 2026 Information Brochure](https://cetcell.mahacet.org/wp-content/uploads/2023/12/IB_MCA_CET2026.pdf). Confirm them against the current year's brochure on [cetcell.mahacet.org](https://cetcell.mahacet.org/).

| Section | Questions | Marks |
|---|---|---|
| Mathematics & Statistics | 30 | 60 |
| Logical / Abstract Reasoning | 30 | 60 |
| English Comprehension & Verbal Ability | 20 | 40 |
| Computer Concepts | 20 | 40 |
| **Total** | **100** | **200** |

The paper has 90 minutes for all sections, uses four-option MCQs, is taken online and is in English only. **There is no negative marking.**

## Run it locally

You need Node 20 or newer. There are no dependencies to install.

```sh
npm run dev      # build into site/ and serve at http://localhost:4321
npm run check    # validate all content without building
```

## Add or fix content

All study material lives in `content/maths.mjs`, `reasoning.mjs`, `english.mjs` and `computer.mjs`, with the word list in `content/vocab.mjs`. [`content/README.md`](content/README.md) describes the format. Marathi translations live in `content/mr/` (format in [`content/mr/README.md`](content/mr/README.md)), and interface text is in `content/i18n.mjs`. The build fails if a translation is missing or doesn't line up with its English topic. The build rejects a topic that has no analogy, a question whose options are not exactly four, an answer index outside 0–3, or unescaped HTML. Every push to `main` is validated and deployed to GitHub Pages by `.github/workflows/pages.yml`.

If you find a wrong answer, please [open an issue](https://github.com/BaluRaut/mca-cet-prep/issues) and include the topic and question number.
